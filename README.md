# 🐍 Snake

Eine eigene Implementierung des Klassikers **Snake**, umgesetzt in C# (.NET / Visual Studio).

## Über das Projekt

Dieses Projekt entstand im Rahmen der IMS-T-Ausbildung als Übung zur Umsetzung eines einfachen Spiels mit Game-Loop, Kollisionserkennung und Tastatursteuerung.

## Voraussetzungen

- [.NET SDK](https://dotnet.microsoft.com/download)
- Visual Studio 2022 (oder neuer) mit installierter .slnx-Unterstützung

## Installation & Start

```bash
git clone https://github.com/LoicDev2010/Snake.git
cd Snake/28_Snake
```

Danach `28_Snake.slnx` in Visual Studio öffnen und das Projekt starten (F5), oder per CLI:

```bash
dotnet run
```
